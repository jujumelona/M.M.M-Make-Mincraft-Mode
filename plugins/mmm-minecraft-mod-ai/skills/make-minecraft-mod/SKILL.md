# Make Minecraft Mod

Use this as the plugin front door. Route requests to the canonical M.M.M skills instead of duplicating their policies.

- New mod: `intake-mod-brief` -> `research-minecraft-evidence` -> `plan-game-design` -> `freeze-approved-spec` -> `execute-complete-production`.
- Existing mod: `inspect-existing-project` -> `patch-existing-project` -> `compile-and-repair`.
- Resume: `resume-production-run`.
- Release: `release-security` -> `publish-release` after release verification.

Keep version, evidence, generation, and validation authority with the canonical skills and MCP stages.
